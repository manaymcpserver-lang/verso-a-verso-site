Release 1.0.0 (5). Real Android emulator recording, using fictional local test data. Two recordings are joined: opening the app and declining/reopening consent; then accepting consent, enabling the service, blocking the selected Chrome app, opening the Bible and pausing the blocker. No review access code or personal account appears in this video.

The optional service only checks the foreground app identifier against the user's selected apps. It does not read messages, passwords or typed text, and does not transmit this identification or selection to a server. The blocker can be paused or switched off, and accessibility permission can be revoked in Android Settings. It is not an accessibility tool for disabilities.
