# Verso a Verso — site de pré-lançamento

Site estático preparado para GitHub Pages. O repositório fica privado e o site **não deve ser publicado ainda**: faltam domínio, e-mail de apoio, identidade legal e revisão final de privacidade/termos.

## Antes de publicar

1. Confirmar o nome e a titularidade legal da app.
2. Criar o e-mail de apoio no domínio e os canais para pedidos de privacidade.
3. Finalizar e rever as páginas de Política de Privacidade, Termos de Utilização e Apoio com o comportamento real da versão de lançamento.
4. Confirmar produto, duração da experiência gratuita, preços regionais e texto aprovado do paywall no App Store Connect.
5. Substituir a pré-visualização ilustrativa por capturas verificadas da versão final; verificar direitos de cada imagem/texto.
6. Só então tornar o repositório público, ativar GitHub Pages e configurar o domínio/HTTPS.

O site não usa cookies, formulários, analytics ou bibliotecas externas. A pré-visualização é uma ilustração em HTML/CSS, não uma captura da app.
